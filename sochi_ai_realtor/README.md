# Sochi AI Realtor (Multi-Agent Framework)

Полностью автономная мультиагентная система по продаже недвижимости в Сочи.

## Архитектура
Система базируется на следующих технологиях:
- **Backend:** Python 3.11+, FastAPI
- **Оркестрация Агентов:** LangGraph
- **LLM Провайдеры:** OpenAI (GPT-4o), Anthropic (Claude 3.5 Sonnet)
- **Базы данных:** PostgreSQL (реляционные данные), Qdrant (векторная БД для RAG)
- **RPA / Парсинг:** Playwright
- **Инфраструктура:** Docker, Yandex Cloud (Kubernetes, Managed PostgreSQL)

## Агенты в Системе
1. **Главный ИИ-Директор (Orchestrator):** Принимает стратегические решения, анализирует цены, распределяет бюджет, делегирует задачи.
2. **ИИ-Маркетолог:** Генерация текстов, креативов, определение ЦА.
3. **ИИ-Таргетолог / SEO:** Запуск рекламы.
4. **ИИ-Брокер (Listing Agent):** Размещение объявлений.
5. **ИИ-Коммуникатор (Sales Agent):** Общение с клиентами, отработка возражений, закрытие сделок.
6. **ИИ-Юрист:** Генерация и проверка договоров.

## Структура Проекта
Проект построен с использованием Clean Architecture (Domain-Driven Design):
- `src/domain/`: Сущности предметной области (Models), Pydantic схемы.
- `src/core/`: Ядро приложения (настройки, логирование, guardrails).
- `src/infrastructure/`: Базы данных, HTTP клиенты, LLM интеграции, RPA.
- `src/agents/`: Ланграфы и логика конкретных агентов (Директор, Коммуникатор).
- `src/services/`: Бизнес-сервисы, связывающие агентов и инфраструктуру.
- `src/api/`: FastAPI эндпоинты (REST, Webhooks).
